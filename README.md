# royharmon.com

Personal site for Roy Harmon - B2B SaaS marketing leadership.

Static HTML/CSS/JS, deployed on Netlify.

## Deploy
Connected to Netlify via GitHub: push to `main` and it deploys automatically.

## Structure
- `index.html` / `services.html` / `pricing.html` / `about.html`
- `styles.css` - design system
- `site.js` - scroll reveal, counters, nav
- `netlify.toml` - redirects from retired URLs + headers
